## Разработка Системы Управления Задачами
Простая система управления задачами (Task Management System) с использованием Java, Spring.
Система обеспечивает создание, редактирование, удаление и просмотр задач.
Каждая задача содержать заголовок, описание, статус (например, "в ожидании", "в процессе", "завершено"), приоритет (например, "высокий", "средний", "низкий") и комментарии, а также автора задачи и исполнителя.
Реализовано только API.

## Описание:
1. Сервис поддерживает аутентификацию и авторизацию пользователей по email и паролю.
2. Доступ к API аутентифицирован с помощью JWT токена. Access и refresh токены находятся в cookie на стороне пользователя.
3. Создана ролевая система администратора и пользователей.
4. Администратор может управлять всеми задачами: создавать новые, редактировать существующие, просматривать и удалять, менять статус и приоритет, назначать исполнителей задачи, оставлять комментарии.
5. Пользователи могут управлять своими задачами, если указаны как исполнитель: менять статус, оставлять комментарии.
6. API позволяет получать задачи конкретного автора или исполнителя, а также все комментарии к ним. Реализована фильтрация и пагинацию вывода.
7. Сервис корректно обрабатывает ошибки и возвращать понятные сообщения.
